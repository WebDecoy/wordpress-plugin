# README checkout demonstration

`woocommerce-checkout.gif` is a 960×540, 8fps, approximately 10-second looping excerpt of the published [48-second WooCommerce demo](https://youtu.be/pYzsU-EGO_0). It uses the same WebDecoy-branded, controlled-lab footage; it introduces no new test results.

The source segments are 9–13s, 18–24s, 34–40s and 42–46s, each played at 2× speed. They show three synthetic failures, refusal of the next checkout, a separate accepted offline test order, and the installation CTA. The README labels the excerpt as condensed and sped up and links to the full test scope.

Test setup, observations and limitations: https://webdecoy.com/blog/woocommerce-bot-protection-checkout-carding-fake-orders/

The existing plugin build excludes `/docs`, so the animation is for GitHub documentation and is not added to distributed plugin packages.
